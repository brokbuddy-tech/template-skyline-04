# **App Name**: Monks Estate Pro

## Core Features:

- AI Chatbot: Integrate an AI chatbot (AI Orb embed code) for user assistance, fixed in the bottom-right corner.
- Dynamic Pages: Implement dynamic pages that read Property IDs from the URL to fetch and display property-specific data.
- Search Functionality: Enable property search with location input, property type dropdown, and advanced search options.
- Map Integration: Include a 'Map' link in the navigation bar to display property locations.
- Currency Switcher: Add a currency switcher in the footer to allow users to select between USD, AED, EUR, and GBP.
- Mortgage Calculator: Implement a mortgage calculator on the property detail page with fields for loan amount, interest rate, and loan term. Include a tool that generates 'Suggested Rate'.

## Style Guidelines:

- Primary background: Pure white (#FFFFFF) for a minimalist look.
- Primary text: Pure black (#000000) for high contrast and readability.
- Secondary text: Medium gray (#888888) for sub-headlines to provide a softer contrast.
- Borders & Dividers: Light gray (#EAEAEA) for subtle separation of content sections.
- Inverted background: Pure black (#000000) for the footer and main CTA buttons to create a strong visual contrast.
- Headlines: 'Playfair' (serif) for logo and major section headlines, providing an elegant and high-fashion feel.
- Body/UI: 'Inter' (sans-serif) for all other text (nav links, body copy, card text, buttons, etc.) to ensure a clean and geometric look.
- Splash Animation: Use the 'Logo Draw & Fill' animation with the new 'Monks' serif logo for a 3-second splash screen that cross-fades into the homepage.
- Page Transitions: Implement a sharp and fast 'Black Panel Wipe' with a 400ms transition speed.
- Scroll-Into-View Animations: Apply a smooth, slightly slower 'Fade-in & Slide-up' (opacity: 0 to 1, translateY: 20px to 0px) with a timing of 600-800ms for an elegant feel.
- Header/Navigation Layout: Sticky positioning at the top with a solid white background and a 1px light gray border on the bottom.
- Footer Layout: A massive, full-screen-height (100vh) inverted footer with a solid black background and all white text. 4-column layout (Logo/About, Links, Socials, etc.).
- Use minimalist icons for services and amenities, maintaining a clean and consistent style.
